Πώς βρίσκει η GPS τη συντομότερη διαδρομή;

Κάθε GPS χρησιμοποιεί τον αλγόριθμο Dijkstra για να υπολογίζει τις ελάχιστες αποστάσεις ανάμεσα σε σταθμούς ενός οδικού δικτύου με θετικές αποστάσεις.

Σε κάθε γύρο του παιχνιδιού σου δίνεται ένα τυχαίο οδικό δίκτυο G(n,p) με δύο τοποθεσίες — αφετηρία και προορισμός — και καλείσαι να επιλέξεις τους δρόμους που αποτελούν τη συντομότερη διαδρομή.

Ξεκίνα τώρα 
GPS — Dijkstra(G, s):
  d[s] = 0 km  (αφετηρία)
  d[v] = ∞     για κάθε v ≠ s
  Σ = ∅        (επισκεφθέντα)

  ενώ |Σ| < |V|:
    u = τοποθεσία εκτός Σ με min d[u]
    Σ.add(u)

    για κάθε γείτονα v του u (δρόμος):
      if d[u] + w(u,v) < d[v]:
        d[v] = d[u] + w(u,v)
